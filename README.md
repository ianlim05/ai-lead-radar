# AI Lead Radar

An automated Python pipeline designed to accelerate B2B sales research for Global Business Services (GBS), Shared Services, and Center of Excellence (COE) setups. 

**Key Features:**
* **News Monitoring:** Aggregates and deduplicates articles from Google News, Bing News, and custom RSS feeds.
* **AI Lead Scoring:** Uses the Gemini API to analyze headlines, score lead quality (1-5), and draft personalized LinkedIn outreach messages.
* **Safe LinkedIn Enrichment:** Integrates Scrapfly API to extract public company descriptions and employee counts using a 100% account-safe, no-login meta-tag scraping method.
* **Historical Tracking:** Exports data to a continuous CSV file while preserving previous leads and salesperson notes.
